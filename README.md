# Daily Board

A simple and elegant Daily Task Planner built with HTML, CSS, and JavaScript. It helps you organize your daily tasks by status, category, and priority while keeping everything stored locally in your browser.

#Features

Task Management

Add new tasks
Edit task titles
Delete tasks
Store tasks using localStorage

Multiple Views

Board — organize tasks by Not Started, In Progress, and Done
Category — organize tasks by Personal and Work
Priority — organize tasks by High, Medium, and Low

#Drag & Drop

Easily move tasks between columns
Reorder tasks within columns
Visual drop indicators

#Task Details

Task title
Category
Priority
Status

#Productivity Features

Motivational messages when completing tasks
Confetti animation for completed tasks
Refresh option to remove completed tasks
Reset option to clear the entire board
Collapsible columns

#Responsive Design

Works on desktop, tablet, and mobile devices

# Getting Started

Clone the repository:

git clone https://github.com/your-username/daily-board.git


Open the project folder:

cd daily-board


Then open index.html in your browser.

No backend or database is required.

💾 Data Storage

Tasks are saved automatically in the browser using LocalStorage. This means your tasks remain available after refreshing or reopening the page on the same browser.

Clearing your browser's site data will also remove the saved tasks.

🎯 Purpose

Daily Board was created to provide a lightweight and visually pleasing way to manage everyday tasks without requiring an account, server, or complicated setup.
